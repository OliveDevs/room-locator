            Code text:

            Check everything

            Checks the website, the site key, the passcode and the console link.

              How to put in a new site key
              1. On a phone, scan the console's Staff page code (the last spots on its map, after the staff PIN). That way the console's link is renewed in the same step. A laptop works too, but then press Link the console afterwards.
              2. Sign in to GitHub with the account that owns the room-locator repository and open New fine-grained token ↗
              3. Repository access: Only select repositories, room-locator. Permissions: Contents, Read and write. Pick the longest expiration GitHub allows and note the date.
              4. Generate it, copy it, come back here and press the button below. Paste it with its date and the staff passcode.
              5. Press Check everything again. Every line should say OK.

              Passcode and sign-out

              Staff passcode

              Anyone with this passcode can save to the website. It's separate from the console PIN. Use more than 4 digits.

              Console link

              Lets a phone that scans the console's Staff page code save without typing anything. Redo it only if the console or its card is replaced.

              Unlock the console with its PIN, then show it this code. You only see it once.

              This device

              After signing out, this device needs the console's Staff page code or the passcode to save again.

              Help
              • The console PIN starts as 1234. To change it on the console: press Down past the last picture on Home, press Select, then choose Change staff PIN.
              • Shelves are numbered from the bottom.
              • This page shows the website's copy of the room. If it disagrees with the console, the console is right.
              • Made a mistake? On the console, open Recent changes, pick the change and press Select twice. A newly added item can only be removed with Start over.
              • Start over on the console clears every change and every item added there. To reset the website too, use the button below.
              Start over: put the website back to the Nov 16 setup

              Use this with Start over on the console so the two match. It removes every change and edit made since Nov 16.
