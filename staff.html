Staff tools

Make a code on your phone and show it to the Room Locator's scanner. The console shows what will change, lights the old and new spots, and asks for the staff PIN before it saves anything.

Link the console: nothing to type on phones

After this, any phone that scans the console's Staff page code (on its map) or a To the website code can save. Both sit behind the console's staff PIN, so the PIN is the only thing staff need to know.

Show this to the console once. It is not shown again: if the console is ever replaced or its card wiped, press Link the console again.

Or a staff passcode to type

For a laptop away from the console. Anyone who types it on the staff page can save to the website. It is separate from the console's PIN.

A locked copy of the site key is stored on the public site. A 4-digit passcode can be guessed by a program that tries all 10,000, so a longer one is safer. The key can only change this website's files.

        Good to know

        • The PIN is checked on the console, never on this page. It starts as 1234. Change it on the console: press Down past the last picture on Home, Select, then go to the last spot on the map, "Change staff PIN".
        • Shelf numbers count grooves from the bottom. If a board was taken out for something tall, the console puts things on the board below.
        • This page reads the website's copy of the room. Moves made at the console since the last update are not shown here, so the console's own screen is the one to trust.
        • A new item added with a code exists on the console right away. Its guide page appears on this site after "From the console" brings it over and you press Save.
        • How many Lending has: "Edit an item" saves the number to the website, then shows a code for the console so it knows too.
        • Several changes at once: every code you make is kept in a list under the QR. Set them all up, then show them to the console with Next code. The PIN is typed once.
        • "From the console" always makes the website match the console exactly, including changes that were taken back there. With no changes on the console it puts the website back to the Nov 16 setup.
        • A mistake on the console can be taken back there: Recent changes, then pick any change and press Select twice. Adding a new item cannot be undone one at a time, only with Start over.
        • Start over (the last spot on the console's map, behind the PIN) takes back every change and every item added at the console. "From the console" on this page has the matching button for the website.
